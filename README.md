# 🎰 CazinoProjectSlepPas — Desktop App (WPF)

Интерактивное десктопное приложение "Казино", разработанное на платформе **WPF (.NET 8)**. Проект включает систему регистрации, личный профиль и игровые механики.

---

### 📖 Функционал приложения

#### 🔐 Авторизация и Безопасность
* **Регистрация и Вход:** Реализована система проверки пользователей через `BaseUsers.cs`. Данные хранятся в словаре (Dictionary) для быстрой проверки логина и пароля.
* **Валидация данных:** Проверка даты рождения пользователя при регистрации.

#### 👤 Личный кабинет
* **Профиль:** Отображение данных пользователя и текущего баланса.
* **Баланс:** Динамическое обновление баланса (реализован интерфейс `INotifyPropertyChanged` для мгновенного обновления интерфейса при изменении счета).
* **Касса:** Страница для управления внутриигровыми средствами.

#### 🎮 Игровой процесс
* **Разнообразие игр:** Включает страницы для популярных механик: **Crash**, **Miner** и другие.
* **Интерфейс:** Современный дизайн с использованием `BlurEffect` и кастомных графических ресурсов.
* **Навигация:** Использование `Frame` в `MainWindow` для бесшовного переключения между страницами (Login, Register, Game).

---

### 🛠 Технический стек
* **Язык:** C#
* **Платформа:** Windows Presentation Foundation (WPF)
* **Framework:** .NET 8.0
* **Паттерны:** Базовая реализация MVVM (уведомления об изменении свойств).
